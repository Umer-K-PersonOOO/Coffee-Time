A canvas implementation of recursive watercolor-like polygon deformation. The panels show the process: base polygon, one deformation pass, recursive roughening, and a final stacked low-opacity splotch that uses the layered center-concentration trick from the transcript.

1. Start polygon

Simple base polygon. Each original edge gets its own magnitude-variance multiplier.

2. One deformation pass

For each edge: sample a Gaussian point on the edge, noisy outward angle, and positive length.

3. Three recursive loops

The large form becomes organic while later recursive magnitudes are slightly nerfed.

4. Five recursive loops

More shoreline-like detail. Child edges inherit local softness or sharpness.

5. Six recursive loops

Fine detail appears, but later rounds are kept smaller so the shape does not balloon too much.

6. Final stacked low-opacity splotch

Three bands of layers: base deformed 1 round + 3 detail rounds, then 2 + 3, then 3 + 3. This keeps only a touch more pigment near the center.

7. Multi-color interaction test

Several independently seeded splotches drawn into the same paper surface. Overlaps use multiply blending so transparent pigment layers visibly interact.

What changed: the center is less opaque, later recursive rounds are slightly smaller, and the final render now follows the transcript’s layering strategy: first third from a 1-round base, second third from a 2-round base, final third from a 3-round base, with 3 extra deformation rounds applied per layer in every band. The “midpoint” remains on the edge, and only the jut vector moves outward.
